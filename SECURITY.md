# Security

This is an archived private research repository. It no longer accepts live
submissions and has no actively supported production deployment.

Do not commit API keys or other credentials. Local keys belong in the ignored
`bot/.env`; `bot/.env.example` contains placeholders only.

If a credential or security issue is discovered, use a private GitHub Security
Advisory for this repository. Do not open a public issue containing secrets,
private API payloads, or personal identifiers.

Tournament-era credentials should be revoked or rotated independently of the
repository. The post-event scan found no committed credential in the current
tree or reachable Git history.
